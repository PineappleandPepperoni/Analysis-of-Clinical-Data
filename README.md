# Analysis-of-Clinical-Data
I analyze clinical data published in papers using Python functions like Panda and matplotlib.
The Python file termed "Diets in 2022.py" is an analysis of a survey https://pmc.ncbi.nlm.nih.gov/articles/PMC10708400/ that explains the proportion of diets adhered to by American adults in 2022.
For this project, I practiced using matplotlib to form a bar graph outlining the above.
I had to label the graph, reformat the labels, and compare percentages.

For the Python file termed "Dropinbp.py" I analyzed the file here: https://pubmed.ncbi.nlm.nih.gov/33275398/, which is a meta-analysis of the effect of plant-based diets on blood pressure in a 2021 study.  Since this is only one study of many, I stated that the blood pressure drop was only an estimate.
